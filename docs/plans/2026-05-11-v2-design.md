## 1. Context

The current repo (`develop_mattec` baseline = `main`) was written by Matteo during his Master's thesis at Nova SBE while still learning Python. A 3-agent audit (2026-05-11) of structure, code quality, and methodology identified:

- The DFM core is a **correct** Python port of the FRBNY Banbura-Modugno mixed-frequency DFM (Bok et al. 2018). Pseudo-real-time vintage backtest is methodologically sound.
- ~85% of root-level Python is **near-duplicate**: 18 `nowcast_YYYY[_fiscal].py` files, 2 ~1000+ line Streamlit dashboards.
- **Four candidate methodology bugs** identified pre-verification (audit-verification 2026-05-11 confirmed two, partially confirmed one, refuted one — see `docs/audit/v1-verified/00_synthesis.md`):
  1. ~~GCEC1 mis-aligned by 2 months vs GDPC1 in tent aggregation~~ — **refuted**: the shift is the correct ingestion into the project's third-month-of-quarter convention.
  2. MTSDS133FMS loaded as raw `lin` (non-stationary, strong April seasonality) → "Q2 fiscal effect" is partly a calendar artefact — **confirmed** (April = +1.13σ; `ch1` shrinks to 0.12σ).
  3. Diebold-Mariano tests run at weekly granularity (N=652 = 34 quarters × 19.17 vintages) instead of quarterly (T≈30) — **confirmed**, plus stacked bug: code is plain `scipy.stats.ttest_1samp` despite Appendix C claiming HAC.
  4. W875RX1 mis-labelled as "fiscal" — **partially confirmed**: mislabel real (FRED definition: market income *ex* transfers), but the redundancy claim is refuted on the `pch` transform actually used (r=0.09 full sample; r=0.99 only on levels). Series kept in spec.
- **2 reproducibility blockers:**
  - `Functions/update_Nowcast.py` is missing from HEAD → all `nowcast_YYYY*.py` scripts fail with `ModuleNotFoundError` on clean clone. (Recoverable from this repo's own git history at `729b40b` — see §3 Phase 3 and §8 risks.)
  - FRED API key committed in plaintext at `variables_creation.py:25` (already burned, must rotate).
- 144 hardcoded Windows paths, no `.gitignore`, no tests, 209 MB repo (97 MB `.git`), unpinned `requirements.txt`.

Full audit reports in `docs/audit/v1/`:
- `00_synthesis.md` — unified synthesis across the three audits
- `01_structure_audit.md` — folder structure + reproducibility
- `02_code_quality_audit.md` — Python code quality
- `03_methodology_audit.md` — statistical/econometric correctness

This document specifies a complete revision (v2) targeting both **portfolio piece** (primary) and **working paper** (secondary).

### Key structural decisions

- **`src/` layout** (not flat) — clean `pip install -e .`, no import conflicts with `scripts/`.
- **Distribution name `gdpnowcast-fiscal`**, import name `gdpnowcast` — explicit namespace to avoid PyPI collision.
- **`dfm.py` as a single file** (with `# region:` sections), NOT split into a sub-package. Splitting was deferred — we'll split only if after de-MATLAB-ization the file still exceeds ~800 lines AND there are clean boundaries. Premature splitting moves complexity without reducing it.
- **No `scripts/` directory** — replaced by `src/gdpnowcast/cli.py` (Typer) + `justfile` for one-liners.
- **Vintage list is NOT Fridays-only** — `fridays_between(start, end)` alone drops the 33 quarter-start (Jan/Apr/Jul/Oct 1-3) vintages the DFM re-estimates parameters on. Use a **committed vintage manifest** generated from the 485 real filenames, or augment `fridays_between` with each quarter's first business day. Sample range lives in `configs/runtime.toml`.
- **Single config layer**: `configs/spec_us_*.xlsx` for signal specs (FRBNY-compatible) + `configs/runtime.toml` for runtime params. No YAML, no dataclass-as-config.
- **`docs/dashboard_data/`** committed (CSV/Parquet, ~5 MB) for Streamlit Cloud deploy. Live FRED fetching cannot be done from Streamlit Cloud (ephemeral disk, secrets management).
- **`outputs/` is fully gitignored**; paper figures live in `docs/paper/figures/` (committed).

## 6. Methodology scope per phase

### Phase 4 — Methodology fixes

**Revised 2026-05-11 after agent verification** (see `docs/audit/v1-verified/00_synthesis.md`). Two of the v1 audit's four "bugs" were refuted or de-scoped:

- **Bug #1 (GCEC1 shift) — DROPPED from Phase 4.** Verification refuted it: the `shift(2)` is the correct ingestion of FRED's quarter-start stamp into the project's "third-month-of-quarter" convention. Removing the shift would silently drop GCEC1 (NaN reads on rows 2/5/8/…), not misalign it. Replaced by a unit test that `pca(GDPC1)` matches BEA-published Q-over-Q growth — guards the convention against future regression.
- **Bug #4 (W875RX1) — DROPPED from Phase 4.** Verification showed the redundancy claim breaks on `pch` (r=0.09 full sample; largest divergences in fiscal-transfer events — CARES, ARP). Series stays in `Spec_US_fiscal.xlsx` as-is, including the `Category=Fiscal` label. The taxonomic mislabel debate is parked.

| Bug | Fix | Notes |
|---|---|---|
| MTSDS133FMS loaded as `lin` (raw levels, seasonal) | **Default: `ch1` (12-month difference).** Fallback X-13 ARIMA-SEATS if Q2 seasonality survives | Empirically validated: April is +1.13σ on raw `lin`; `ch1` shrinks the gap to 0.12σ (9× reduction). |
| DM tests at weekly granularity (N=652) + plain `ttest_1samp` despite Appendix C claiming HAC | **Quarterly final-week DM (T≈30 ex-2020) with Harvey-Leybourne-Newbold (1997) small-sample correction.** Bootstrap as robustness check. **HAC kept out of scope** for now (the v1 code never had it; matching Appendix C is a separate scope expansion). | DM code is in `dashboard_nowcast_fiscal.py:1324-1417`, not in `Functions/`. Rewrite cleanly in `src/gdpnowcast/analysis/diebold_mariano.py`; do not port from v1. Expected effect: ex-2020 DM 6.40 → ~1.46 (borderline p≈0.15). |
| (new) `pca(GDPC1)` convention regression test | Unit test reproducing BEA-published Q-over-Q annualised growth for GDPC1 within 0.05 pp tolerance. | Protects against future off-by-one edits to `load_data.py:144` indexing. Documents the (confusing but correct) "last-month-of-quarter" stamping convention. |
| (new) Power / MDE on the headline null | Given the estimated SD of the quarterly loss differential and T (≈10-30), report the **minimum RMSE improvement detectable at 80% power, α=0.05**. Optionally a TOST/equivalence test or a CI on the loss differential instead of a bare p-value. | The headline "non-redundant but not significant" is an underpowered failure-to-reject; without this a reviewer can flip it to "consistent with a real but undetectable improvement". Promoted from `00_synthesis.md:86` / `04_dm.md:162`, which the go-forward plan had dropped. |

### Phase 6 — Validation rigor

| Component | Scope |
|---|---|
| Power / MDE & equivalence | Given the estimated SD of the quarterly loss differential and T (≈10-30), report the minimum detectable RMSE improvement at 80% power, α=0.05; optionally a TOST/equivalence test or a CI on the loss differential instead of a bare p-value. State the headline as inconclusiveness, not "no effect". |
| Forecast-encompassing | `(y_t − ŷ_baseline_t) = β (ŷ_fiscal_t − ŷ_baseline_t) + ε_t`, t-test on β=0, run at quarterly level. |
| Holdout split | Train spec on **2017-2022**, evaluate strictly on **2023-2025**. Report both numbers. |
| Predictive intervals | Convert `Vsmooth` (Kalman state covariance) → variance of GDP point forecast via delta method. Plot 68% / 95% bands. |
| SPF benchmark | **Best-effort** — skip if alignment proves messy; mention in "future work". |

### Phase 7 — Staff Nowcast 2.0 features

- **7a (mandatory): COVID outlier-adjustment device** — an *identifiable* outlier/dummy treatment (Lenza-Primiceri 2022 style, or inflate measurement-error variance R for 2020:M3-M9), which the closed-form Gaussian EM can fit. Unlocks 2020 from headline metrics. A genuine *separate COVID factor* (σ_covid scale + outlier vector) is an SV/Bayesian construct the EM cannot identify — it stays in the excluded Bayesian track, not shipped here implying parity with Staff Nowcast 2.0. Exit is identification-aware (see §7), not an RMSE point target. ~1-2 d.
- **7b (optional): long-run trend `g_t`** — useful for post-2020 baseline. ~2-3 d, only if Phase 7a runs under budget.
- **Excluded:** time-varying volatility (paper-only nice-to-have, not critical), full Bayesian estimation incl. a true COVID *factor* (5+ days, diminishing returns).
